# Web搜索技能

## 描述
当用户需要获取实时信息、最新数据或外部知识时，使用网络搜索工具进行信息查询。

## 触发条件
- 用户询问实时信息（如"今天的新闻"、"最新的技术"）
- 用户请求的信息超出训练数据范围
- 元认知引擎检测到知识缺口且建议搜索
- 意图分析器识别为 QUERY 类型且复杂度 > 0.5

## 执行步骤
1. **查询优化**
   - 分析用户原始问题
   - 提取关键搜索词
   - 生成多个搜索变体以提高覆盖率

2. **执行搜索**
   - 调用 `web_search` 工具
   - 设置合理的搜索结果数量（默认5-10条）
   - 控制搜索超时时间（默认30秒）

3. **结果评估**
   - 检查搜索结果的相关性
   - 过滤低质量或不相关的内容
   - 评估信息来源的可信度

4. **信息整合**
   - 提取关键信息点
   - 去重和合并相似内容
   - 按重要性排序

5. **响应生成**
   - 结合上下文生成自然语言回答
   - 引用信息来源
   - 标注信息的时效性

## 使用工具
- **web_search**: 
  - 参数: `query` (搜索关键词), `num_results` (结果数量, 默认5)
  - 返回: 搜索结果列表，包含标题、摘要、URL

## 注意事项
- **安全性**: 不搜索违法、暴力、色情相关内容
- **隐私保护**: 不搜索个人敏感信息
- **准确性**: 对矛盾信息进行交叉验证
- **透明度**: 明确告知用户信息来自搜索引擎
- **失败处理**: 如果搜索失败，礼貌说明并尝试其他方式
- **资源限制**: 单次搜索不超过30秒，避免过多API调用

## 示例

**用户**: "2024年最新的AI发展趋势是什么？"

**执行**:
1. 生成搜索词: "2024 AI trends", "artificial intelligence development 2024"
2. 调用 web_search(query="2024 AI发展趋势", num_results=8)
3. 分析结果，提取关键趋势
4. 整合生成回答

【搜索结果】
